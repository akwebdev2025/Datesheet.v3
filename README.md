# PU 3rd Semester DateSheet Simplifier

A standalone GitHub Pages app for Panjab University BA/BSc FYUP 3rd Semester (Under NEP), November/December 2026.

## Deploy
Upload `index.html` and the `assets` folder to the GitHub Pages repository root. The dataset is embedded in the HTML. Keep the exact path `assets/pu-template.png`.

## Use
Search by subject/code, choose categories, tick papers, then choose **Generate / Print PDF**. In the browser print dialog choose **Save as PDF**. The export now uses the same Semester 1 poster artwork/template, with 3rd semester heading, exam time, and selected subject rows inserted dynamically. It paginates after eight selected papers per poster page to preserve legibility.

## Dataset
294 subject entries extracted from the uploaded official university PDF. Categories: IDC, DSC, SEC, VAC, Compulsory Punjabi/HCP, AEC, and Minor. Please cross-check each selected paper against the official PDF and your eligibility/admit card; this is a convenience tool, not an official university service.
